# 🎮 GAME-MOTOR (Electron 2D/3D Game Engine Editor)

![Status](https://img.shields.io/badge/Status-Work%20in%20Progress%20%2F%20WIP-yellow?style=for-the-badge)

**GAME-MOTOR** is a desktop HTML5/WebGL game editor built on Electron and JavaScript. It features scene visualization, transform gizmos, undo/redo state management, and an integrated console panel.

---

## 📌 Project Status

- **Status:** 🟡 **Work in Progress (WIP)**
- **CI/CD:** Automated GitHub Actions Node.js build workflow active.

---

## 🚀 Key Features

- **Visual Editor Panel:** Interactive camera controls, object selection, and transform gizmos.
- **Undo / Redo Architecture:** Undo and redo scene mutations seamlessly.
- **Scene Serialization:** Export and load scene graphs as JSON.

---

## 🛠️ Installation & Execution

```bash
npm install
npm start
```
