# 🎮 GAME-MOTOR (Electron 2D/3D Game Engine Editor)

![Status](https://img.shields.io/badge/Durum-Geli%C5%9Ftirilmeye%20A%C3%A7%C4%B1k%20%2F%20WIP-yellow?style=for-the-badge)

![Electron](https://img.shields.io/badge/Electron-20%2B-blue?style=for-the-badge)

**GAME-MOTOR**, Electron ve JavaScript mimarisi üzerine kurulmuş, HTML5/WebGL oyun geliştirme editörüdür. Sahne görselleştirme, gizmo kontrolleri, undo/redo desteği ve konsol paneli sunar.

---

## 📌 Proje Durumu (Project Status)

- **Durum:** 🟡 **Geliştirilmeye Açık / WIP (Work in Progress)**
- **Test & CI/CD:** GitHub Actions Node.js derleme hattı aktif.

---

## 🚀 Özellikler

- **Görsel Editör Paneli:** Kamera kontrolleri, nesne seçimi ve Gizmo entegrasyonu.
- **Undo / Redo Mimarisi:** Sahne değişikliklerini geri alma / yineleme.
- **Scene Serialization:** Sahne objelerini JSON formatına dönüştürme ve yükleme.

---

## 🛠️ Kurulum ve Çalıştırma

```bash
npm install
npm start
```
